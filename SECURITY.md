# Security reports

Report security problems through [GitHub Issues](https://github.com/devkcud/ydl-re/issues/new).

Issues are public. Include the version, operating system, affected behavior, and a sanitized reproduction. Do not include credentials, signed URLs, private files, or sensitive exploit details. This project does not currently provide a private reporting channel or a guaranteed response deadline.

There is no stable release yet. Reports against the current development version are welcome; historical versions have no promised maintenance window. Initial binary releases target Linux/amd64 only. See the [platform matrix](docs/platforms.md) and [security boundaries](docs/security.md).
